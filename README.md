# 아트머그 커미션 페이지

리깅 작가의 커미션 안내 페이지입니다. 페이지는 **GitHub Pages**에 올리고, 아트머그 프로필에는 **iframe**으로 끼워 넣어 보여 줍니다.

- **보는 사람**: 커미션을 의뢰하려는 분. 작가 소개, 작업물, 가격, 신청 양식을 빠르게 확인합니다.
- **고치는 사람**: 작가 본인. 개발 지식 없이 **관리자 페이지**(`admin.html`)에서 비밀번호로 로그인해 고칩니다.

목표는 **단순함**입니다. 기능을 늘리기보다 의뢰인이 보기 쉽고 작가가 고치기 쉬운 쪽을 우선합니다.

---

## 왜 외부 호스팅 + iframe인가

아트머그 HTML 편집기에 직접 붙여 넣으면 `<style>` 등이 걸러져서 디자인이 깨졌습니다. 그래서 페이지는 외부(GitHub Pages)에 두고, 아트머그에는 그 페이지를 띄우는 `<iframe>` 한 줄만 넣습니다.

- 아트머그 쪽에는 iframe 태그만 들어갑니다. JS는 필요 없습니다.
- 페이지 안에서는 JS를 쓸 수 있어서, 작가는 내용만 고치고 화면은 자동으로 만들어집니다.

## 파일 구성

| 파일 | 설명 | 작가가 고치나요? |
|---|---|---|
| `content.json` | 소개, 작업물, 콜라보, 가격, 신청 양식 등 **모든 내용** | 관리자 페이지로 고침 |
| `admin.html`, `admin.js`, `admin.css` | 관리자 페이지 | 아니요 |
| `admin-key.json` | 비밀번호로 잠근 저장용 열쇠(토큰). 처음 설정 때 자동 생성 | 아니요 |
| `style.css` | 디자인. 맨 위 테마 색상만 바꿀 수 있음 | 색 바꿀 때만 |
| `index.html` | 페이지 뼈대 | 아니요 |
| `app.js` | `content.json` 내용을 화면에 그리는 코드 | 아니요 |
| `images/` | 프로필, 콜라보 사진 (관리자 페이지에서 올리면 자동 저장) | 아니요 |
| `artmug.html` | 아트머그에 붙여 넣을 iframe 코드 | 주소만 한 번 |
| `preview.html` | 아트머그에 들어간 모습을 컴퓨터에서 미리 보는 용도 | 아니요 (업로드 안 해도 됨) |
| `LICENSE` | 저작권 안내 (모든 권리 보유) | 코드 저작권자 이름만 한 번 |

## 페이지 구성

1. **About Me**: 작가 소개
2. **Portfolio**: 리깅 영상 카드. 누르면 영상과 크레딧이 뜸
3. **Collaboration**: 함께 작업한 아티스트 카드. 화살표로 옆으로 넘김
4. **Price**: 옵션 비교표와 가격
5. **Apply**: 신청 양식. 의뢰인이 복사해서 아트머그 신청서에 붙여 넣음

## 기능 요구사항 (FR)

| ID | 요구사항 |
|---|---|
| **FR1_1** | 작가 소개(프로필 이미지, 활동명, 짧은 소개글, 태그)가 들어가야 한다. |
| **FR2_1** | 작업물(리깅 영상)을 유튜브 썸네일 카드 그리드로 보여 줘서 많이 스크롤하지 않고 훑어볼 수 있어야 한다. |
| **FR2_2** | 카드를 누르면 반투명 창이 뜨고, 왼쪽에는 유튜브 영상, 오른쪽에는 제목과 크레딧이 나와야 한다. (모바일에서는 위아래 배치) 창을 닫으면 영상도 멈춰야 한다. |
| **FR2_3** | 작가는 **유튜브 주소, 제목, 카테고리, 크레딧**만 입력해서 작업물을 추가하거나 수정할 수 있어야 한다. |
| **FR2_4** | 카테고리 버튼으로 작업물을 걸러 볼 수 있어야 한다. 버튼은 작업물의 카테고리로 자동 생성된다. |
| **FR2_5** | 작업물이 한 페이지에 6개를 넘으면 페이지 번호 버튼으로 넘겨 볼 수 있어야 한다. 카테고리를 바꾸면 1페이지로 돌아간다. |
| **FR2_6** | 포트폴리오 아래에 함께 작업한 아티스트(프로필, 이름, 역할)를 카드로 보여 주고, 화면에 다 들어가지 않으면 화살표로 옆으로 넘겨 볼 수 있어야 한다. |
| **FR3_1** | 옵션들을 표(매트릭스)로 비교할 수 있어야 하고, **마지막 행에 가격**이 나와야 한다. |
| **FR3_2** | 표 아래에 옵션별 카드(이름, 가격)가 있고, 카드를 누르면 작은 팝업으로 설명이 떠야 한다. 팝업의 "이 옵션으로 신청하기"를 누르면 신청 양식에 그 옵션이 선택된 채로 이동한다. |
| **FR3_3** | 추가 옵션(이름, 기본가)을 페이지가 길어지지 않도록 다단 목록으로 보여 준다. 가격은 기본가이며 작업에 따라 달라질 수 있다는 안내를 함께 표시한다. |
| **FR4_1** | 의뢰인이 신청 양식을 페이지에서 작성(선택지는 버튼으로 하나 선택, 다시 누르면 취소 / 나머지는 직접 입력)하고, 버튼 하나로 작성한 내용을 복사해 아트머그 신청서에 붙여 넣을 수 있어야 한다. (아트머그 규정상 외부 연락처는 표시하지 않는다) |

### 관리자 페이지

| ID | 요구사항 |
|---|---|
| **FR-A1** | 작가만 내용을 고칠 수 있어야 한다. 의뢰인(보는 사람)은 아무것도 바꿀 수 없다. 작가는 비밀번호 하나로 로그인/로그아웃한다. |
| **FR-A2** | 프로필(이름, 이름 옆 작은 글씨, 이름 위 문구, 소개글, 태그, 사진)을 수정할 수 있어야 한다. |
| **FR-A3** | 포트폴리오를 추가, 수정, 삭제할 수 있어야 한다. 작업물은 카테고리 순서(Light → Standard → Premium → Wallpaper)로 자동 정렬되고, 같은 카테고리 안에서만 순서를 바꿀 수 있다. 새 작업물은 그 카테고리의 맨 앞에 들어간다. |
| **FR-A4** | 콜라보 아티스트를 추가, 수정, 삭제하고 순서를 바꿀 수 있어야 한다. |
| **FR-A5** | 사진을 올리면 정사각형으로 자르고 작게 줄여서 저장한다. |
| **FR-A6** | 로그인한 상태에서 관리자 비밀번호를 바꿀 수 있어야 한다. |

## 처음 한 번: 올리고 아트머그에 연결하기

1. [GitHub](https://github.com)에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository** → 이름을 정하고(예: `commission`) **Public**으로 만듭니다.
3. 저장소 화면에서 **uploading an existing file**을 눌러 아래 파일을 끌어다 놓고 **Commit changes**를 누릅니다.
   - `index.html`, `style.css`, `app.js`, `content.json`, `admin.html`, `admin.js`, `admin.css`, `images/`, `LICENSE`, `README.md`
   - 올리기 전에 `LICENSE`의 `[코드 저작권자 이름]`을 채워 주세요.
4. 저장소의 **Settings** → **Pages** → Branch를 `main`, 폴더를 `/ (root)`로 정하고 **Save**합니다.
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. (예: `https://아이디.github.io/commission/`)
6. `artmug.html`의 iframe 한 줄을 아트머그 HTML 편집기에 붙여 넣습니다. (현재 주소: https://jiho6362.github.io/commision/)
7. 틀 높이는 화면 폭에 따라 자동으로 정해집니다(PC 4600px, 휴대폰 약 6100~6800px). 휴대폰에서는 카드가 한 줄씩 쌓여 페이지가 길어지기 때문입니다. 틀이 항상 페이지보다 조금 길어서 '창 안의 창' 없이 아트머그 글의 일부처럼 이어지고, 휴대폰에서도 막힘 없이 밑으로 넘겨 볼 수 있습니다. 영상 창과 가격 팝업은 누른 위치 근처에 뜹니다. 섹션을 크게 늘려 아래가 잘리면 `artmug.html`의 높이 숫자를 키웁니다.

## 처음 한 번: 관리자 비밀번호 정하기 (저장소 주인)

관리자 페이지는 저장소에 직접 저장합니다. 저장하려면 GitHub 열쇠(토큰)가 필요하고, 이 열쇠를 **비밀번호로 잠가서** 저장소에 넣어 둡니다. 비밀번호를 모르는 사람은 열쇠를 쓸 수 없습니다.

1. GitHub → 오른쪽 위 프로필 → **Settings** → 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. 아래처럼 정하고 **Generate token**을 누릅니다.
   - Token name: `commision admin`
   - Expiration: 가장 길게 (만료되면 이 과정을 다시 해야 합니다)
   - Repository access: **Only select repositories** → `commision`
   - Permissions → Repository permissions → **Contents: Read and write**
3. 나온 토큰(`github_pat_...`)을 복사합니다. **다른 사람에게 보내지 마세요.**
4. `https://jiho6362.github.io/commision/admin.html?setup` 에서 토큰과 관리자 비밀번호(8자 이상)를 넣고 **등록하기**를 누릅니다.
5. 1~2분 뒤 `https://jiho6362.github.io/commision/admin.html` 에서 그 비밀번호로 로그인할 수 있습니다. 작가분에게는 **비밀번호만** 알려 줍니다.

- 비밀번호만 바꿀 때는 관리자 페이지의 **설정** 탭을 씁니다. 토큰이 만료되면 4번을 다시 하면 됩니다.
- 비밀번호는 길고 추측하기 어렵게 정해 주세요. 잠긴 열쇠 파일은 공개 저장소에 있어서, 짧은 비밀번호는 시간을 들이면 풀릴 수 있습니다.

## 내용 고치기 (작가용)

1. `https://jiho6362.github.io/commision/admin.html` 에 들어가 비밀번호로 로그인합니다.
2. **프로필 / 포트폴리오 / 콜라보** 탭에서 고칩니다.
   - 포트폴리오: 유튜브 주소를 그대로 붙여 넣으면 됩니다. 비워 두면 '비어있음' 칸으로 보입니다. 카테고리를 넣으면 **Light → Standard → Premium → Wallpaper 순서로 자동 정렬**되고, 새 작업물은 그 카테고리 맨 앞에 들어갑니다.
   - 같은 카테고리 안의 순서는 **↑ 위로 / ↓ 아래로**, 지우기는 **삭제**.
   - 비밀번호는 **설정** 탭에서 바꿀 수 있습니다.
   - 사진은 올리기만 하면 자동으로 정사각형으로 잘리고 줄어듭니다.
3. 아래 **저장하기**를 누르면 1~2분 뒤 사이트와 아트머그에 반영됩니다. 아트머그는 다시 고칠 필요가 없습니다.
4. 다 끝나면 오른쪽 위 **로그아웃**. ("이 기기에서 로그인 유지"를 켜지 않았다면 탭을 닫아도 로그아웃됩니다)

- 저장하기 전에는 사이트에 아무것도 바뀌지 않습니다.
- 모든 저장은 GitHub에 기록되므로, 실수했을 때 이전 상태로 되돌릴 수 있습니다.
- 가격, 추가 옵션, 신청 양식은 아직 관리자 페이지에 없습니다. 바꿀 때는 `content.json`을 직접 고칩니다.

## 컴퓨터에서 미리 보기 (개발용)

파일을 더블클릭해서 열면 유튜브 영상이 재생되지 않습니다(에러 153). 로컬 서버로 열어야 합니다.

```sh
python3 -m http.server 8765
```

- 일반 페이지: http://localhost:8765/
- 아트머그 안에 들어간 모습: http://localhost:8765/preview.html
